## What Needs Work (The Pain Points)

### Design & UX
- **Outdated aesthetic** — built on "Neo" website builder (pre-2015 look, rigid layout)
- **Fixed-width layout** — 960px width, not responsive to mobile
- **Absolute positioning** — elements scattered with hard-coded pixel coordinates (inflexible)
- **Poor typography hierarchy** — inconsistent text sizing and spacing
- **No clear primary CTA** — no prominent "Get a Quote" or "Call Now" button above fold
- **Expired SSL certificate** — red flag for security/maintenance

### Technical Issues
- **Platform lock-in** — tied to Neo builder for all updates (slow, expensive)
- **Heavy payload** — external CDN calls, inline styles, bloated HTML structure
- **Mobile broken** — fixed 960px layout collapses on phones (mobile is 80%+ of site traffic)
- **Slow updates** — builder platform required, not self-service updates

### Content Gaps
- **No pricing/tiers** — prospects can't self-qualify before calling
- **Weak value prop** — "quality above all else" is vague (what makes them different?)
- **Testimonials buried** — "Testimonials" page exists but not embedded on homepage
- **No trust signals** — missing: licenses, insurance, certifications, awards
- **Limited before/after** — gallery exists but no dramatic transformations
- **Service area unclear** — doesn't state if local only or wider region

### Conversion Issues
- **Multi-click friction** — key info scattered across pages, not on hero
- **Weak call-to-action** — no "Same-day estimates" or urgency messaging
- **Contact form** — location/design unclear in current structure
